### Decision: Inquiry No. field in project forms

The project create form's "Inquiry No." field is always "—" (projects created directly are never linked to an inquiry at creation time). Removing it keeps Row 1 clean as [Project Id, Company]. The project edit form's `inquiryNumber` is a read-only reference; removing it from the edit form is consistent since the project detail page already shows the linked inquiry. No data is lost.
